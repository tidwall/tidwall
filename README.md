### About me

I'm an independent programmer working on high-performance software.

### Contributing to my software

Here are general guidelines that extend to all of my projects, but each individual project may have additional requirements.

- **[Bugs]** If you find a bug in my software, file an issue. Include a detailed description and steps to reproduce the problem.
- **[New features]** I don't accept new features without prior discussion. If you or your company needs a specialized feature, make sure to express your willingness to fund the work and maintenance.
- **[Pull requests]** Do not open a pull request without filing an issue and/or discussing it with me beforehand. If the PR button is disabled or locked, contact me directly. I can enable access on a case-by-case basis.

Drive-by and low-effort contributions will be closed without notice.

### Software support

I do not respond to every request over Github. If you need priority support, contact me directly.
